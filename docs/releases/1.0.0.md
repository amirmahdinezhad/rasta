# Rasta 1.0.0

Rasta adds right-to-left reading to Codex, T3 Code, Antigravity, Claude, OpenCode, ZCode, Grok Bot, and Gemini on macOS. It detects text direction automatically and lets you set it for individual replies, choose a reading font and adjust spacing.

- Download `Rasta-1.0.0-darwin-arm64.dmg` for Apple Silicon Macs running macOS 13.5 or later.
- Drag **Rasta.app** to **Applications**. Open **Library**, turn on a connection, then choose **Launch** when preparation finishes.
- Use **Library** for connection updates, recovery and removal, and **Settings → Rasta app updates** for Rasta app updates. Connection update checks use the signed Library feeds for this release series.

This release restarts public version numbering at 1.0.0. If you have a higher-numbered version, install Rasta from the DMG manually. Use **Install bundled Rasta 1.0.0** in the connection's **Installation** tab to move a higher-numbered connection to this release. Choose **Launch** after preparation.
