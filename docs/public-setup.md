# Public connection packages and local testing

Open Rasta.app and select the host in Library. Library verifies the signed
package and stages the connection before asking for Launch. The Apple Silicon 1.0.0 candidate includes all eight connections. The exact
signed candidate is shared directly with the owner for Library acceptance.

Keep the previous connection installed until starting the replacement in
Library. Record the offered version, verified package, completed installation
after Launch, displayed version and working host for each connection. Use the
exact accepted public DMG and updater ZIP for publication, then repeat the
Library check against the public feeds.

See [the release workflow](development-workflow.md) for build and acceptance
commands.
